Module 1 : CRM - path "/crm"
1.a Senior Leads : {path: "/"}, 
- To add new senior lead, under contacts tab click on "+ Add New" button to add a new senior lead
- if you want to add send bulk messages to senior leads, you can use  " all selection" checkbox to select all leads or select specific leads and then click on "Send Bulk Message" button
- To add Senior lead aggrement or medical details, click on name of the senior lead from the list you can see 4 different tabs - Biography, Medical, care plan (ADL's and health) and Documents.
-  by clicking on three vertical dots on the right side of senior lead grid row and clicking  onboard, if you provide an email to senior lead, you can onboard them to assistly portal
 - if you click on initiate esign, all the documents under senior lead will be sent for e-sign
 - if you click on move to clinical, senior lead will be moved to clinical module.  
 the esign is only for new senior leads if senior are with the home before the home started using assistly care you can just move them to clinical.
 - you can also see milestones for new senior leads, initial contact, home tour, getting biographical information and sending documents for e-sign.   
- you can also check previous campaign histories under "Campaigns history" tab

1.b Referral Agents : {path: "/referral"}, click on "+ Add New" button to add a new referral agent
- same capaign functionality as senior leads
-  you can change status of referral agents from contacted, not contacted, follow up required and not interested and click save. you can edit or delete referral agents by clicking on three vertical dots on the right side of referral agent grid row.


1.c Care Leads : {path: "/pcg"}, click on "+ Add New" button to add a new care lead.
- same three vertical dots functionality as senior leads
- by clicking on name of care lead you see the document management section for that particular care lead, you can add required documents for that care lead, you can view edit or delete the added documents.


1.d Nurse Leads : {path: "/nurse"}, click on "+ Add New" button to add a new nurse lead

Module 2 : Clinical - path "/clinical"
2.a Senior :{path: "/"}
select list view  from right side of the page
- same functionality with clicking on name of senior lead to see details but additionally you have facesheet tab which shows all the information of the senior lead
- by clicking on 3 vertical dots on the right side of senior lead grid row you can see options to  onboard to assistly portal, add medication, medpass, incident report and initiate esign for any new documents.

- for medication you can add, edit, delete medications for the senior lead you can also do bulk add upload a medication list document our service will extract the medication list and add it to the senior lead.

2.b Care Team :{path: "/pcg"}

- same functionality with clicking on name of care team to see details but additionally you have facesheet tab which shows all the information of the care team
- same 3 vertical dots functionality as crm module care team but without onboarding option  


2.c Nurse :{path: "/nurse"}
- same functionality with clicking on name of nurse to see details but additionally you have facesheet tab which shows all the information of the nurse
- same 3 vertical dots functionality as crm module nurse but without onboarding option
